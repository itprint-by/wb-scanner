ITPRINT Scanner 6.0
Загрузить index.html, manifest.webmanifest, sw.js и три PNG в корень репозитория. catalog.json оставить текущий.
Safari: Поделиться → На экран Домой. Android Chrome: меню → Установить приложение / Добавить на главный экран.

Резервная версия 5.1 находится в отдельном архиве, не загружать его на сайт.
